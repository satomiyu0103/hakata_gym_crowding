## 受け入れ基準（AC）

### FR-FETCH-001（混雑状況取得）

- [ ] フィクスチャ JSON から train / gym の人数・`time_calc`・閾値をパースできる
- [ ] HTTP 失敗時は指数バックオフで最大 3 回リトライし、最終失敗で `RuntimeError`
- [ ] `maintenance=1` のとき `RecordStatus.MAINTENANCE` になる
- [ ] `time_calc` が現在から 5 分以上離れているとき `RecordStatus.STALE_DATA` になる（記録自体は継続）
- [ ] naive `datetime` を JST として stale 判定する

### FR-FETCH-002（天気取得）

- [ ] フィクスチャ HTML から天気ラベル・最高/最低気温・風速・風向・降水確率を取得できる
- [ ] HTML 取得失敗時は混雑取得を止めず、天気列は空欄・備考に失敗理由

### FR-STORE-001 / FR-STORE-002（履歴保存・列スキーマ）

- [ ] 新規シートに日本語 16 列ヘッダーを自動作成する
- [ ] 1 実行で 16 列 1 行を `append_row` する（取得時間・計測時間を別列）
- [ ] ヘッダー不一致時は `A1:P1` を正しいヘッダーで更新する（`values` 先行の gspread API）
- [ ] 旧 6 列行を新 16 列に変換できる（移行スクリプト）
- [ ] 不正な旧行は行単位でスキップし、有効行のみ移行を継続する

### FR-SCHED-001（定期実行・開館判定）

- [ ] JST 9:00 未満または 22:00 以降は `should_run=False`（`outside_hours`）
- [ ] 毎月第 3 月曜は休館（`third_monday`）
- [ ] 第 3 月曜が祝日の翌火曜は休館（`substituted_tuesday`、yesterday 基準）
- [ ] 12/28〜1/4 は休館（`new_year`）
- [ ] `--force` 指定時は休館判定をスキップして取得できる

### FR-LOG-001（エラーログ）

- [ ] スキップ・エラー・成功を `logs/run.log` に 1 行追記する
- [ ] ログに API キー等の秘密情報を含めない

### FR-LOG-002（障害 Slack 通知）

- [ ] `SLACK_WEBHOOK_URL` 未設定時は POST しない
- [ ] ERROR（config / fetch / sheets）の exit 1 時のみ Webhook へ POST する
- [ ] 天気 WARN・maintenance・休館スキップ・成功時は POST しない
- [ ] 通知本文に Webhook URL・認証 JSON パス・長い ID を含めない
- [ ] 同一 stage の ERROR は 15 分以内 1 回まで（重複抑制）
- [ ] Webhook POST 失敗時も CLI の exit code は変えない（`warn slack=` を run.log に追記）
