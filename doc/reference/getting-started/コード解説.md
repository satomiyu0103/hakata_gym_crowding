# コードガイド

各ファイルが「何をしているか」「なぜそう書いているか」を解説します。
コードを読む前に [入門ガイド.md](入門ガイド.md) とあわせて参照すると理解しやすくなります。

処理の流れを日本語変数で追いたいときは [d-format/README.md](d-format/README.md) を参照する。
作成手順は [.cursor/skills/d-format-code-guide/SKILL.md](../../../.cursor/skills/d-format-code-guide/SKILL.md)。
