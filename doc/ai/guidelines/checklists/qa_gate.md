# チェックリスト — QA ゲート（MVP 着手前）

最終更新: 2026-08-15

> 根拠: [08_検証設計.md](../../../specs/08_検証設計.md) / [02_要件定義.md](../../../specs/02_要件定義.md) / [testing_rules.mdc](../../../../.cursor/rules/testing_rules.mdc)

**目的**: 要件・設計の抜け漏れを **コード・Agent MVP の前** に塞ぐ。  
**合格**: A〜G の必須項目で未達ゼロ、または未達ごとに [01_ABC見送り・ギャップ台帳.md](../../../specs/01_ABC見送り・ギャップ台帳.md) へ起票済み。  
**Windows デスクトップ MVP**（GUI + グローバルホットキー + 画面キャプチャ）では **§H も必須**。

---

## A. 要件の検証可能性

- [ ] MVP 対象の **Must FR** すべてに [08_検証設計.md](../../../specs/08_検証設計.md) の受け入れ基準（AC）がある  
  - 根拠: [08_検証設計.md §受け入れ基準](../../../specs/08_検証設計.md)
- [ ] AC に曖昧語（「使いやすい」「高速」等）が残っていない。残る場合は測定可能な条件に書き換え済み  
  - 根拠: [02_要件定義.md](../../../specs/02_要件定義.md)
- [ ] [08_検証設計.md §MVP スコープ宣言](../../../specs/08_検証設計.md) で Must / MVP 外が明示されている  

## B. 設計技法（抜け漏れ防止）

- [ ] 条件分岐が複雑な Must FR に **デシジョンテーブル** がある（目安: 条件 3 本以上）  
  - 根拠: [08_検証設計.md §デシジョンテーブル](../../../specs/08_検証設計.md)
- [ ] 状態が変わる Must FR に **遷移一覧表（2b）** がある。禁止遷移は `許可=×` の行で残している  
  - 根拠: [08_検証設計.md §状態遷移](../../../specs/08_検証設計.md)
- [ ] 状態 ≤5・操作 ≤10 の FR では **遷移マトリクス（2a）** も記載している（省略時は理由を 08 に 1 行メモ）  

## C. 観点・境界

- [ ] **テスト観点表** に正常・境界・異常の観点がある  
  - 根拠: [08_検証設計.md §テスト観点表](../../../specs/08_検証設計.md)
- [ ] 数値・文字数・日付等の制約がある FR で **境界値** が観点表または AC に含まれている  

## D. トレーサビリティ

- [ ] **検証マトリクス** で MVP の Must FR がすべてカバーされている  
  - 根拠: [08_検証設計.md §検証マトリクス](../../../specs/08_検証設計.md)
- [ ] MVP 外の FR が [04_機能一覧.md](../../../specs/04_機能一覧.md) または 08 のスコープ宣言と一致している  

## E. 非機能要件（NFR）

- [ ] MVP で実施する Must NFR に **検証方法** が [08_検証設計.md §NFR 検証方法](../../../specs/08_検証設計.md) に書いてある  

## F. 自動化方針

- [ ] Must FR の AC が unit / integration テストに落とせる（手動のみの AC には理由がある）  
  - 根拠: [testing_rules.mdc](../../../../.cursor/rules/testing_rules.mdc)
- [ ] Agent 指示に FR コード + AC 参照を含められる状態である（例: 「FR-XXX-001 の AC をすべて満たせ」）  

## G. Agent 向け（AI 開発）

- [ ] テストを削除して Green にしない旨を Agent ルールまたは作業指示に含められる  
  - 根拠: TDD + Agent 運用（[08_検証設計.md](../../../specs/08_検証設計.md) 関連ドキュメント）

## H. Windows デスクトップ MVP（該当時のみ）

> 該当: tkinter / PyQt 等の常駐 GUI + グローバルホットキー + 画面キャプチャ。詳細: [desktop-windows-mvp-spec-gates.md](../desktop-windows-mvp-spec-gates.md)

- [ ] `02_要件定義.md` に **想定利用環境（検証必須）** がある（副モニター・負座標・対象アプリ）
- [ ] UI 状態の永続化（モニター選択等）が該当 FR に明記されている
- [ ] `03_システム設計.md` に **プラットフォーム制約** 節がある（tkinter 負座標、OS 予約キー、フォーカス復元）
- [ ] OS 予約キー（PrintScreen 等）の Go/No-Go が要件または ADR で決まっている
- [ ] `08_検証設計.md` に **実機確認 M1〜M5** が Must としてある
- [ ] 利用者設定 JSON（個人情報を含みうる）が Git 除外されている（`.gitignore` + `*.example.json`）
