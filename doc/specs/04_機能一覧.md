## 採番ルール

### コード体系

```
[TYPE]-[CATEGORY]-[NNN]

TYPE:  FR = 機能要件  /  NFR = 非機能要件

CATEGORY（FR 用）:
  <!-- 業務ドメインに合わせて定義する。例: -->
  AUTH  = 認証・ログイン
  FEAT  = 主要機能
  ADMIN = 管理機能

CATEGORY（NFR 用）:
  SEC   = セキュリティ
  PERF  = パフォーマンス
  OPS   = 運用・保守

NNN: カテゴリ内の連番（001〜）。欠番は振り直さない。
```

### 運用ルール

- 新機能追加時: 該当カテゴリの最大連番 + 1 で採番する
- 機能廃止時: 実装状況を「廃止」に変更する（行は削除しない）
- カテゴリ追加時: このファイルの CATEGORY 定義に追記する
