# 機能一覧

最終更新: 2026-09-05

---

## 採番ルール

### コード体系

```
[TYPE]-[CATEGORY]-[NNN]

TYPE:  FR = 機能要件  /  NFR = 非機能要件

CATEGORY（FR 用）:
  FETCH = データ取得
  STORE = 保存
  SCHED = 定期実行
  LOG   = ログ

CATEGORY（NFR 用）:
  SEC   = セキュリティ
  PERF  = パフォーマンス
  OPS   = 運用・保守

NNN: カテゴリ内の連番（001〜）。欠番は振り直さない。
```

## 非機能要件（NFR）

| NFR コード | 種別 | 機能名 | 実装状況 | 概要 |

## 実装状況の凡例

| 値 | 意味 |
|---|---|
| 未着手 | 実装していない |
| 実装済 | 実装・動作確認済み |
| 廃止 | スコープ外にした |
| 検討中 | 要件が未確定 |
