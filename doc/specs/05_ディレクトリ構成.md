# ディレクトリ構成

最終更新: 2026-09-05

---

## リポジトリルート

```
hakata_gym_crowding/
├── config/
│   ├── .env.example          # 環境変数テンプレート
│   └── service-account.json  # Google 鍵（Git 除外・手動配置）
├── doc/
│   ├── reference/setup/      # Sheets・Scheduler 手順
│   └── specs/                # 要件・設計・CHANGELOG
├── logs/                     # 実行ログ（Git 除外）
├── scripts/                  # 運用スクリプト（秘密パターン検査等）
├── src/
│   └── hakata_gym_crowding/  # アプリ本体
├── tests/
│   ├── fixtures/             # JSON サンプル
│   └── test_*.py
├── main.py                   # CLI ラッパー
├── pyproject.toml
└── uv.lock
```

---

## 主要パスの責務

| パス | 責務 |
|---|---|
| `src/hakata_gym_crowding/` | 取得・判定・保存・CLI |
| `tests/` | pytest 単体テスト |
| `config/` | `.env` と Google サービスアカウント |
| `logs/` | `run.log`（定期実行の結果） |
| `doc/specs/` | 要件・設計・機能一覧 |
| `doc/reference/setup/` | 初回セットアップ手順 |
