# Windows デスクトップ MVP — 要件・設計ゲート

最終更新: 2026-08-15

> **由来**: 電子書籍 PDF 化デスクトップアプリ（tkinter + グローバルホットキー + 画面キャプチャ）の実機 FB から昇格。  
> **用途**: `src/` 着手前・MVP プロトタイプ後の仕様見直し時に参照する。

---

## いつ使うか

| タイミング | 使い方 |
|---|---|
| **要件定義の直後** | 02 に「想定利用環境」「OS 制約」を書き込むチェックリストとして使う |
| **設計確定前** | 03 にプラットフォーム制約・UI 永続化方針を追記する |
| **08 / QA ゲート** | 実機確認（M1〜M5）を Must に含める |
| **実装後 FB** | sessions へ経緯を書き、本ガイドまたは specs へ昇格する |

---

## 1. 想定利用環境を「検証必須」まで落とす

「サブモニターで使う」等の一文だけでは不十分。**テスト環境の条件**まで書く。

| 項目 | 書く内容（例） |
|---|---|
| OS | Windows 10 / 11 |
| ディスプレイ | **2 台以上**。副モニターが主モニターと **異なる座標**（左配置で `left < 0` を含む） |
| 対象アプリ | ブラウザ上の電子書籍ビューア（Chrome / Edge 等） |
| 本アプリの位置 | 主または副のいずれか。書籍は副モニター縦置きが典型 |

**防げる FB**: 毎回モニターダイアログ、副モニターで範囲指定不可。

---

## 2. FR を「できること」だけで終わらせない

| 領域 | 足りないと起きる FB | 要件に足す一文 |
|---|---|---|
| 全画面キャプチャ | 毎回モニター選択 | **最後に選んだモニターを設定に保存し、起動時に自動適用** |
| 任意矩形 | 副モニターでドラッグ不可 | **全物理モニター上で矩形指定できる**（仮想 1 ウィンドウ前提にしない） |
| ホットキー | OS 予約キーと競合 | **MVP では F1〜F12 等、競合しないキーのみ**。PrintScreen 等は Wont または ADR で Go/No-Go |
| 撮影＋送り | ブラウザがページ送りしない | **撮影直前のフォアグラウンドを保存し、撮影後に復元してから送りキーを送る** |
| セッション終了 | 終了方法が分からない | **終了キーに加え Esc・画面上の終了ボタン**。0 枚時は PDF なしで終了 |
| 利用者設定 | 個人情報の誤コミット | **`user_settings.json` は Git 除外**。正本は `*.example.json` のみ |

---

## 3. 設計に「プラットフォーム制約」節を置く

GUI・OS API を選んだら、**制約表**を 03 に書く（実装後に初めて知らない）。

| 制約 | 設計への影響 |
|---|---|
| tkinter の `geometry(+負のX)` | 仮想デスクトップ 1 枚のオーバーレイは不安定 → **モニター単位の Toplevel** |
| Windows 11 の PrintScreen | Snipping Tool と競合。pynput だけでは不十分 → **MVP 非対応を要件で先に決める** |
| PyAutoGUI のキー送信 | フォーカスが自アプリ側だと届かない → **`window_focus` 相当の復元を CTL に含める** |
| グローバルホットキー | 別スレッドで検知 → **キュー経由でメインスレッド実行**（tkinter 安全） |

---

## 4. デシジョンテーブルで実装前に分岐を固定する

| 条件 | 結果（例） |
|---|---|
| キャプチャモニター未保存 | コンボ既定値を起動時適用 |
| 保存モニターが切断 | 接続中の先頭へフォールバック＋メッセージ |
| ホットキー = OS 予約キー | 保存拒否または一覧に含めない |
| 撮影時 FG ≠ 対象アプリ | HWND 復元後に送りキー |
| 範囲指定キャンセル | 直前の確定座標を維持 |

---

## 5. 実機確認チェックリスト（モックでは検知できない）

08 または `qa_gate.md` §H に **Must** として入れる。

| ID | 確認 | 合格条件 |
|---|---|---|
| M1 | 副モニター全画面 | 意図モニターのみキャプチャ、解像度一致 |
| M2 | 副モニター範囲指定 | ドラッグ矩形＝PNG サイズ |
| M3 | ブラウザページ送り | 撮影キー連打でページが進む |
| M4 | ホットキー候補 | 一覧のキーが実機で 1 回は動作 |
| M5 | 設定ファイル | 利用者設定 JSON が Git に含まれない |

---

## 6. 設計レビュー用の最小プロトタイプ（本実装前）

| プロトタイプ | 検証目的 | 目安 |
|---|---|---|
| 副モニターに赤枠オーバーレイだけ | tkinter 配置 | 0.5〜1 日 |
| グローバルホットキー 1 キー + ブラウザ送り | フォーカス・pynput | 0.5〜1 日 |
| OS 予約キー（PrintScreen 等）の Go/No-Go | ADR で却下可能に | 0.5 日 |
