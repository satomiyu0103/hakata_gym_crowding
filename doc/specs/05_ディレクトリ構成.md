├── logs/                          （Git 除外）

## 主要パスの責務

| パス | 責務 |
|---|---|
| `src/` | アプリケーション本体（スタック選定後に構築） |
| `tests/` | テストコード（採用フレームワークに従う） |
| `config/` | 環境変数テンプレート（実値の `.env` は Git 除外） |
| `scripts/` | 初回構築・運用のワンショット（任意） |
| `doc/specs/` | 要件・設計・機能一覧・CHANGELOG・開発日誌索引 |
| `doc/ai/sessions/` | セッション記録本文（背景・意思決定・検証） |
| `doc/ai/decisions/` | 意思決定の横断索引 |
| `doc/reference/setup/` | スタック別セットアップ手順（任意参照） |
| `doc/adr/` | 技術選定 ADR |
