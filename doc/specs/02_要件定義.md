# 要件定義

最終更新: 2026-09-05

## AS-IS（現状）


| 課題                          | 影響                    |
| --------------------------- | --------------------- |
| 混雑状況は公式サイトを都度ブラウザで確認する必要がある | 出発前の判断に手間がかかる         |
| 過去の混雑傾向が残らない                | 曜日・時間帯の傾向を自分で覚える必要がある |


## TO-BE（目指す姿）

指定間隔で公式サイト由来の混雑データを取得し、タイムスタンプ付きで Google スプレッドシートに追記する。
利用者は蓄積データから混雑傾向を参照できる。

### 取得対象


| 項目        | 内容                                                                    |
| --------- | --------------------------------------------------------------------- |
| トレーニング室混雑 | 人数と4段階ラベル                                                             |
| 体育館来場者    | 人数                                                                    |
| 取得元       | [博多体育館 トレーニング室](https://ssk-hakata-gym.com/training/)（p-counter JSON） |



| 表示        | 目安人数   |
| --------- | ------ |
| 空いています    | 0〜14人  |
| やや混雑しています | 15〜24人 |
| 混雑しています   | 25〜29人 |
| 大混雑しています  | 30人以上  |

## 機能要件（FR）


| FR コード       | 機能名    | 優先度    | 概要                                    |
| ------------ | ------ | ------ | ------------------------------------- |
| FR-FETCH-001 | 混雑状況取得 | Must   | p-counter 公開 JSON からトレーニング室・体育館データを取得 |
| FR-FETCH-002 | 天気取得 | Should | トレーニング室ページから天気6項目を取得 |
| FR-STORE-001 | 履歴保存   | Must   | 混雑・天気・日時を Google スプレッドシート（16列）に追記     |
| FR-STORE-002 | 列スキーマ移行 | Should | 旧6列→新16列の移行スクリプト（不正行はスキップ） |
| FR-SCHED-001 | 定期実行   | Should | タスクスケジューラから CLI 実行可能                  |
| FR-LOG-001   | エラーログ  | Should | 取得失敗・スキップ時に `logs/run.log` へ記録        |




## 非機能要件（NFR）


| NFR コード     | 項目   | 優先度    | 概要                   |
| ----------- | ---- | ------ | -------------------- |
| NFR-OPS-001 | 実行間隔 | Should | 過度なアクセスを避ける（30分間隔）   |
| NFR-SEC-001 | 秘密情報 | Must   | 認証情報・個人情報をリポジトリに含めない |
