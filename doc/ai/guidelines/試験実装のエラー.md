# 試験実装のエラー記録

## 目的

実装中に発生したエラーとその対策を記録する。着手前に必読。

「すべてのエラー」を書く帳ではない。**同じ症状が再発しうるもの**だけを残し、人と AI の認知負荷を下げるためのナレッジとする。

---

## 記載する条件（再利用価値のライン）

次のいずれかに当てはまるときは **記載する**。

| 条件 | 説明 |
|---|---|
| 再現しうる | 環境・手順・設定を変えると同じ症状が出る |
| 原因が非自明 | ログ・スタックトレースだけでは直感で分からなかった |
| 調査に時間がかかった | 目安: 15 分以上かかった、または複数の切り分けが必要だった |
| プロジェクト固有 | このリポジトリの構成・依存・規約に紐づく（汎用ドキュメントに載っていない） |
| 再発防止できる | ルール・チェック・テンプレ修正など、**次に防ぐ具体策**を書ける |

### 記載しない（または Issue だけで足りる）

| 対象 | 理由 |
|---|---|
| タイポ・未保存・パス打ち間違い | 再利用価値がほぼない |
| すぐ直った単純な構文・import 漏れ | エディタや linter で防げる |
| 個人 PC だけの一時障害（再起動で解消） | 他メンバーに再現しない |
| 秘密情報の混入 | 値は書かず、`.gitignore` や運用で防ぐ（ログに鍵を残さない） |

迷ったときは **「1 週間後の自分／他の開発者が同じハマりをするか？」** で判断する。Yes なら記載、No なら省略でよい。

### 他ドキュメントとの役割

| 書く場所 | 向き |
|---|---|
| **このファイル** | 症状・原因・対策・再発防止（ナレッジ） |
| `doc/specs/07_CHANGELOG.md` | リリース単位で「何を直したか」（`Fixed` + FR コード） |
| GitHub Issue / PR | 再現手順・議論・レビュー。長い調査はここに詳細を書き、このファイルには要約とリンク |

---

## エラー記録フォーマット

```
### [YYYY-MM-DD] エラーの概要（1行）

**症状**: 何が起きたか
**原因**: なぜ起きたか
**対策**: どう解決したか
**再発防止**: 同じミスを防ぐために何をするか
```

### [2026-08-15] 副モニターで GUI オーバーレイが配置できない（負座標）

**症状**: マルチモニター環境で、副モニター（`left < 0`）上に半透明オーバーレイや範囲指定 UI が動かない  
**原因**: GUI ツールキットの単一フルスクリーンウィンドウが、仮想デスクトップの負座標を正しく扱えないことがある（Windows + tkinter で顕著）  
**対策**: 物理モニター単位でウィンドウを分ける。座標は `x_root` / `y_root` の画面座標で統一  
**再発防止**: [desktop-windows-mvp-spec-gates.md](desktop-windows-mvp-spec-gates.md) §1・§3。08 / qa_gate §H の実機 M2  

詳細: [sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md](../sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md)

### [2026-08-15] OS 予約キー（PrintScreen）とグローバルホットキーの競合

**症状**: 利用者が PrintScreen 等をホットキーにすると、OS 標準機能（例: Snipping Tool）が同時に起動する。抑止するとアプリ側の撮影も動かない場合がある  
**原因**: OS がキーを先に処理する。ライブラリ単体では安定した排他が難しい  
**対策**: MVP では競合の少ないキー（F1〜F12 等）に限定。OS 予約キーは要件で Wont とする  
**再発防止**: [desktop-windows-mvp-spec-gates.md](desktop-windows-mvp-spec-gates.md) §2。実装前に ADR で Go/No-Go  

詳細: [sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md](../sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md)

### [2026-08-15] グローバルホットキー後に対象アプリへキーが届かない

**症状**: 撮影は成功するが、ブラウザ等の対象アプリがページ送り等に反応しない  
**原因**: ホットキー処理後フォーカスが自アプリに残り、キー送信 API が別ウィンドウに届かない  
**対策**: 撮影前のフォアグラウンドウィンドウ ID を保存し、撮影後に復元してから送りキーを送る  
**再発防止**: [desktop-windows-mvp-spec-gates.md](desktop-windows-mvp-spec-gates.md) §2・§5 M3  

詳細: [sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md](../sessions/2026-08-15_desktop-mvp-feedback-spec-lessons.md)

### [2026-06-28] GAS サイドバー表示の権限エラー

**症状**: `Ui.showSidebar` で `script.container.ui` 不足、または「エラーが発生しました。もう一度お試しください。」のみ表示  
**原因**: `appsscript.json` で `oauthScopes` を明示していると UI スコープが自動付与されない。スコープ追加後も旧トークンが残る  
**対策**: `oauthScopes` に `https://www.googleapis.com/auth/script.container.ui` を追加し、GAS エディタから `authorizeContainerUi` を実行して再認可  
**再発防止**: UI（サイドバー・alert）を追加するときは `appsscript.json` のスコープ一覧を確認する  

詳細: [sessions/2026-06-28_control-panel-sidebar.md](../sessions/2026-06-28_control-panel-sidebar.md)

### [2026-07-01] 期限違い商品の誤重複スキップ

**症状**: 商品名が同じで消費期限だけ異なる PDF のうち、後から投入した方が重複スキップされる  
**原因**: シート上の Date 型を `String(date)` で読み込むと期限正規化が空になり、「期限不問」として既存行と重複判定される  
**対策**: Date 列を `yyyy-MM-dd` に変換してから比較。正規化関数で Date オブジェクトも受け付ける  
**再発防止**: シート読み込み・期限正規化のテストに Date オブジェクト・シート Date 文字列のケースを追加する  

詳細: [sessions/2026-07-01_FR-SHT-002-expiration-dup-key.md](../sessions/2026-07-01_FR-SHT-002-expiration-dup-key.md) / [product-schema-design.md](../../reference/setup/product-schema-design.md)
