# 0〜9 を 10 倍して表示

> モード: intent
> 対象: ループで数字を順に処理し、10 倍した結果を表示する
> 最終更新: 2026-07-02

## やりたいこと

0 から 9 までの数字を順に取り出す。
それぞれ 10 倍した値を画面に表示する。

## コード（D形式・標準形）

```python
for 数字 in range(10):          # 0, 1, 2, … 9 を順に取り出す
    十倍した値 = 数字 * 10       # その数字を 10 倍する
    print(十倍した値)            # 結果を画面に出す
```

## 用語

| 用語 | 意味 |
|---|---|
| `range(10)` | 0 から 9 までの数字を順に出す組み込み機能 |
| `print(...)` | 括弧内の値を画面に表示する組み込み機能 |

## よくある誤解

- 「0〜10」は 11 個の数字を指しやすい。`range(10)` は **0 から 9 まで** の 10 個である
- 乗算は半角の `*` を使う。全角の `＊` は Python では使えない
