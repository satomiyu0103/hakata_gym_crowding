## 1. 目的・適用範囲

Web サイト・モバイル Web・管理画面 UI・分析レポート（HTML）で、**可読性・操作性・直感性**を満たすための共通原則。モダンさより **迷わず使える** ことを優先する。

**対象外**: ネイティブ iOS/Android の専用コンポーネント実装（原則のみ annex で触れる）。

## 3. 基本デザイン（DADS foundations 要約）

### タイポグラフィ

- 日本語 UI: **Noto Sans JP**（または OS ゴシック + 同等の読みやすさ）
- コード: **Noto Sans Mono** / `ui-monospace`
- 本文 **16px 以上**、行間 **1.65〜1.8**
- 情報は書体に依存せず伝わること（フォント差で意味が変わらない）

### 余白・レイアウト

- 基準単位 **8px**（padding / gap / margin）
- モバイル Web: **1 カラム**、コンテンツ最大幅はプロジェクト `DESIGN.md` に従う（例: 640px）
- 横スクロールを出さない

### コントラスト

| 用途 | 目標 |
|---|---|
| 本文テキストと背景 | 4.5:1 以上 |
| UI 枠線・非テキスト要素と隣接背景 | 3:1 以上 |

### フォーカス（DADS 共通・変更しない）

キーボード操作時は **黄（#FFEE00）+ 黒の二重リング** で視認性を確保する。プロジェクトで別スタイルを使う場合も、`:focus-visible` を必ず定義する。

```css
:focus-visible {
  outline: 2px solid #FFEE00;
  outline-offset: 2px;
  box-shadow: 0 0 0 2px #000;
}
```

## 4. コンポーネント原則（DADS components 要約）

### ボタン階層

| スタイル | 重要度 | 用途 |
|---|---|---|
| 塗り（プライマリ） | 高 | 画面内で最も重要な 1 アクション（**1 画面 1 つ**） |
| アウトライン（セカンダリ） | 中 | 代替選択肢（同時に最大 3 つまで） |
| テキスト | 低 | キャンセル・補助導線 |

- タップ領域 **44×44 CSS px 以上**（Small サイズは上下余白で確保）
- LTR（日本語・英語）: 進む・決定は右、戻る・中止は左

### よく使う部品の選定

| 部品 | 使う場面 |
|---|---|
| タブ | 同レベルのモード切替（3〜5 区分） |
| カード / パネル | 問題・設定・フィードバックのまとまり |
| 注釈ブロック / 説明リスト | ラベル付きの補足情報 |
| ステップナビ | 手続き型フロー（設定→作業→結果） |
| 通知バナー | 正誤・重要メッセージ（操作不要で表示） |
| ディスクロージャー | 任意の詳細解説 |
| チップラベル | 状態・モードの短い表示 |

詳細仕様: [`dads-markdown-20260819/components/`](../../../../.agents/skills/dads-markdown-20260819/components/index.md)

## 5. アクセシビリティ

- **色だけに頼らない**: 正誤・エラーは文言 + 枠スタイル（実線 / 破線等）
- **キーボード**: すべての操作が Tab / Enter で完結できる
- **タッチ**: 最小 44px、近接ボタンは gap を空ける
- **動き**: `prefers-reduced-motion: reduce` でアニメーションを抑える。点滅・強い pulse は禁止
- **目標**: JIS X 8341-3 適合レベル AA / WCAG 2.1 AA を目安（プロジェクト `DESIGN.md` のコントラスト表と併用）

## 6. 媒体別 annex

### Web 静的（`public/**`）

- モバイルファースト、パネル間余白 1rem 前後
- フォーム: ラベルと入力の関連（`for` / `aria-labelledby`）
- 実装 skill: [ui-ux-implementation](../../.cursor/skills/ui-ux-implementation/SKILL.md)

### モバイル Web

- 主要 CTA を親指の届く位置（ボトム固定可）
- プログレス・チップで「今どこにいるか」を表示

### RPA / Agent 管理 UI

- 一覧・フォームの情報密度はタスクに応じて調整。初見ユーザー向けは余白多め
- エラーはフィールド横 + サマリの二段構え

### DS 可視化・レポート

- グラフの色弱配慮: [chart-format-ja](../../../../.cursor/skills/chart-format-ja/SKILL.md)
- 凡例はプロットと重ならない位置に配置

## 7. エージェント実行チェックリスト

### 着手前

- [ ] 本ガイドラインと `DESIGN.md` を Read した
- [ ] UI 大幅変更なら `ai-design-brief.md` でトンマナを確認した
- [ ] 変更スコープ（パス）を宣言した

### 実装中

- [ ] プライマリ CTA は 1 画面 1 つ
- [ ] インタラクティブ要素は 44px 以上
- [ ] `:focus-visible` を定義した
- [ ] 色は `DESIGN.md` の CSS 変数（ハードコードの行政色なし）
- [ ] 正誤・エラーに文言がある（色のみで伝えない）

- [ ] ローカルでキーボード操作を確認した
- [ ] モバイル幅で横スクロールが出ない
