# 読みやすいコードコメント規約（開発テンプレ正本）

> Agent が生成するコードは、**処理の流れと意図**が追えることを最優先にする。コメントは日本語。自明な import・getter・1 行代入には書かない。

Documents 秘書層の作業コピー: `doc/life/playbook/readable-code-comments.md`（利用者発話の原文あり）

## 適用範囲

| 層 | 参照 |
|---|---|
| Rule（globs 適用） | `.cursor/rules/code_comments.mdc` |
| Skill（手順・例） | `.cursor/skills/readable-code-comments/SKILL.md` |
| ブロック内コメント | `.cursor/skills/junior-code-comments/SKILL.md` |
| stop フック | `.cursor/hooks/check-code-comments.py` |

対象パス: `src/**` · `scripts/**` · `tampermonkey/**` · `**/*.user.js` · `gas/**` · `notebooks/**`（DS テンプレ）

## 4 層（骨格）

| 層 | 書く場所 | 内容 |
|---|---|---|
| **モジュール** | ファイル冒頭 | 役割・含まれるクラス/関数・処理の大枠（番号付き） |
| **クラス** | クラス直前 / docstring | 目的・集まるデータと処理・バリデーション有無 |
| **自作関数** | 関数直前 / docstring | 受け取る・返す/する・処理の流れ（番号付き） |
| **共通** | 非自明な行の直前 | 処理の意図 / エラー修正時の意図 |

## 1. 共通

| 種類 | いつ書く | 書く内容 |
|---|---|---|
| **処理の意図** | **`if` / `for` / `while` / `with` / `try` など基礎構文のブロック直前**（中堅には自明でも、初心者・初見のため **ブロックごとに明記**） | このブロックで何をする処理か（1〜3 行） |
| **エラー修正時の意図** | バグ修正・ワークアラウンド・`try/except` の直前 | 以前の問題・今回の対処・他への影響 |

## 2. モジュール（ファイル冒頭）

- このファイルの役割（1 文）
- 含まれる主なクラス・関数・定数
- 処理の大枠（番号付き 3〜7 ステップ）

## 3. クラス

- **目的**（1 文）
- **集まっているもの**（データ・処理）
- **バリデーション**（型チェック・自動修正の有無。なければ「なし」）

## 4. 自作関数

- **受け取る** — 引数の意味・`null` 時の扱い
- **返す / する** — 戻り値または副作用
- **処理の流れ** — 番号付き 2〜5 ステップ

## 適用の目安

| ティア | 対象 | 義務 |
|:---:|---|---|
| A | 触ったファイルの新規関数・クラス | モジュール冒頭 + 関数/クラスヘッダ |
| B | 触った **`if` / `for` / `while` / `with` / `try`** | **ブロック直前に「何をする処理か」**（自明でも省略しない） |
| C | 1 行ヘルパー | 関数ヘッダのみ |

一括リファクタはしない。**変更した範囲だけ** 足す。
