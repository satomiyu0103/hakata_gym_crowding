## アーキテクチャ概要

```
Windows Task Scheduler
        │
        ▼
  hakata_gym_crowding.cli
        │
        ├─ ScheduleGuard ── skip (休館/時間外)
        │
        ├─ PCounterFetcher ── GET JSON ×2
        │
        ├─ crowding_level ── 人数→4段階
        │
        └─ SheetsWriter ── スプレッドシート追記
                │
                └─ logs/run.log
```

## 外部データ源

| データ | URL |
|---|---|
| トレーニング室 | `https://svc01.p-counter.jp/v4shr3svr/shinko-sports/data/hakata_train.json` |
| 体育館来場者 | `https://svc01.p-counter.jp/v4shr3svr/shinko-sports/data/hakata_gym.json` |

主要フィールド: `sum.area1`（人数）、`threshold.rank1-4`（混雑閾値）、`time_calc`（計測時刻）、`maintenance`。

---

## スプレッドシート列（混雑履歴）

| 列 | 型 | 内容 |
|---|---|---|
| recorded_at | 文字列 | 取得実行日時（JST） |
| train_count | 数値 | トレーニング室人数 |
| train_level | 文字列 | 混雑4段階 |
| gym_count | 数値 | 体育館来場者数 |
| source_time | 文字列 | JSON `time_calc` |
| status | 文字列 | OK / skipped_closed / maintenance / stale_data / error |

---

## 休館・実行時間（ScheduleGuard）

1. JST 9:00 ≤ 現在 < 22:00 以外 → 実行しない（Sheets 非記録）
2. 毎月第3月曜 → 休館
3. 第3月曜が祝日 → 翌火曜も休館（`jpholiday`）
4. 12/28〜1/4 → 休館
5. JSON `special_holiday` → MVP では未使用

---

## セキュリティ・運用

- 秘密情報は `config/.env` と `config/service-account.json`（Git 除外）
- HTTP: タイムアウト 30 秒、指数バックオフリトライ（最大3回）
- stale 判定: `time_calc` が現在から5分以上離れていれば `stale_data`（記録は行う）
- maintenance 時は Sheets へ書き込まない
