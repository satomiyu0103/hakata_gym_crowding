# Django セットアップ・UI/UX（任意スタック）

> **位置づけ**: Django を採用する場合の参考手順と UI 方針の記入テンプレートです。

## 環境構築（概要）

1. Python 環境を [python-uv.md](python-uv.md) に従って用意する
2. `uv pip install django` または `requirements` に追加
3. `django-admin startproject` でプロジェクトを作成し、`src/` またはルートの構成を `05_ディレクトリ構成.md` に記載する

## UI/UX 方針（記入式）

Django プロジェクト向けの方針を以下に記載する。

- レイアウト基準（ベーステンプレート、ブロック構成）
- コンポーネント・CSS フレームワークの選定
- フォーム・バリデーションエラーの表示ルール
- アクセシビリティ方針

テンプレート・views を変更するときは、上記方針と [05_ディレクトリ構成.md](../../specs/05_ディレクトリ構成.md) に従う。変更後はテンプレート構文と画面表示を確認する。

既存プロジェクトから移行する場合は、UI ガイドをこのファイルに転記する。
